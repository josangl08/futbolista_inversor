# Futbolista Inversor - Landing Page

Este repositorio contiene el código fuente de la landing page para el proyecto "Futbolista Inversor", un curso de cultura financiera diseñado específicamente para futbolistas profesionales.

## Descripción del Proyecto

El objetivo de esta landing page es presentar el curso de una manera atractiva y profesional, captar el interés de los futbolistas y dirigirlos a la plataforma de compra (Teachable). La página ha sido completamente personalizada para reflejar la identidad de la marca, utilizando una paleta de colores corporativa, ilustraciones generadas por IA y textos persuasivos.

### Características Principales

- **Diseño 100% Personalizado:** Todos los elementos visuales, desde los colores hasta los iconos, han sido adaptados a la marca.
- **Contenido Relevante:** Textos y testimonios creados para conectar directamente con las necesidades y aspiraciones de los futbolistas profesionales.
- **Ilustraciones Únicas:** Un set de 12 ilustraciones personalizadas generadas por IA para el temario del curso.
- **Diseño Responsivo:** La página se adapta correctamente a diferentes tamaños de pantalla (escritorio, tablet y móvil).
- **Llamadas a la Acción Claras:** Botones y secciones diseñadas para guiar al usuario hacia la inscripción al curso.
